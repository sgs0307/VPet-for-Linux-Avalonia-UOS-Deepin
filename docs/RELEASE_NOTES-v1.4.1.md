# VPet Linux (Avalonia) v1.4.1

小版本，只有一件事：**去掉「数据面板」**。

## 为什么去掉

它是 v1.0 为了"能看见数值"临时做的小浮窗——Lv 标题、金钱、五条蓝色进度条，右下角一个「详细」。
v1.4.0 重做的角色面板已经把同样的数值做得更全：

| 数据面板（已删除） | 角色面板（现在） |
|---|---|
| 等级、金钱、经验 | ✅ 一样，另外有背包 / 相伴天数 / 成就进度 |
| 体力、心情、饱腹、口渴 | ✅ 一样，另外有健康 / 好感度 |
| 五条统一的蓝色进度条 | ✅ 七色属性条，低值转红，悬停有说明 |
| 无 | 能力上限、陪伴记录、陪伴年报 |

留着它的唯一效果是"两处同时刷新同一批数字"，右键菜单还多占一行。

## 改了什么

- 右键菜单去掉「数据面板」，首项现在是「角色面板」
- 删除 `Views/ToolBar.axaml` / `.cs`（这个控件只服务于那个浮窗）
- 删除 `IController.ShowPanel()` 与 `MainWindow.ShowPanel()`
- 面板定位、X11 输入区域计算里不再为它单独留一块
- 数值变化事件只剩角色面板一个订阅者

## 升级

存档、设置、统计、收藏全部沿用，不需要迁移。安装方式不变：

```bash
tar xzf VPet-UOS-v1.4.1-linux-x64-full.tar.gz
cd VPet-UOS-v1.4.1
./scripts/install.sh
```

包仍然是**自包含**的，不需要装 .NET 运行时。

## 验证

`VPET_SELFTEST_ONLY=panels` 七段全过，含角色面板一项：

```
[TEST] 角色面板: 属性条=7(应 7) 页签=3(应 3) 切记录=True 切年报=True 回概览=True
                低值转红=True 恢复=True 经验不误报=True 增量刷新=True
```

右键菜单与角色面板均实机截图核对（X11 / 统信 UOS arm64）。
