# VPet for Linux (Avalonia) v1.3.1 — 统信 UOS / Deepin 适配版

把 Windows 桌面宠物 **VPet（虚拟桌宠模拟器）** 用 Avalonia 重写到 Linux 上的移植版。
透明全屏窗口站在桌面上，可以拖、可以摸、可以喂、可以买东西、可以派去干活睡觉。

这是首次公开发布，包含从 v1.1.0 到 v1.3.1 的全部功能。

---

## 下载哪个包

| 包 | 适用 | 大小 |
|---|---|---|
| `VPet-UOS-v1.3.1-linux-x64-full.tar.gz` | **绝大多数 UOS / Deepin（amd64）**，含桌宠资源，解压即用 | ~990 MB |
| `VPet-UOS-v1.3.1-linux-arm64-full.tar.gz` | 信创机器 / 鲲鹏 / 飞腾（arm64） | ~990 MB |
| `VPet-UOS-v1.3.1-linux-*-nomod.tar.gz` | 已有 `mod/` 目录，或只想看程序本体 | ~9 MB |

不确定自己的架构？终端里跑 `uname -m`：`x86_64` 选 x64，`aarch64` 选 arm64。

## 安装

```bash
# 1. 解压
tar xzf VPet-UOS-v1.3.1-linux-x64-full.tar.gz
cd VPet-UOS-v1.3.1

# 2. 安装（装到 ~/.local/share/vpet，生成桌面快捷方式）
./scripts/install.sh
```

**前提：需要 .NET 8 运行时**（包里不含，控制体积）。
UOS / Deepin 应用商店搜「.NET」，或从 <https://dotnet.microsoft.com/download/dotnet/8.0> 下载
`dotnet-runtime-8.0`。安装脚本会自动找 dotnet 并写死路径到启动器里。

装完桌面上会有「VPet 桌宠」图标，双击启动。卸载：`./scripts/uninstall.sh`。

## 本次更新（v1.3.1）

### 工作 / 学习 / 玩耍面板

把右键菜单里那串纯文本 `[工作] 文案 (60分, 约8/分)` 换成了面板：

- 三个分类分开（工作 5 / 学习 4 / 玩耍 4），带数量角标
- 每项写明：**时长 · 每小时收益 · 做完总收益 · 消耗（食物/水/心情）· 等级要求**
- 等级不足的项压暗，按钮位置直接显示 `Lv.N`，点不动（以前得点进去才弹一句提示）
- ★ 收藏置顶
- 进行中的项绿色高亮，按钮变红「停止」，顶部实时显示 `已工作 X/Y 分（剩 Z 分）已得 N`
- 底部常驻体力/饱腹/口渴/心情，低于 25% 转橙并提示"干活效率会打折"

### 进度条配色跟随 MOD

原版每个工作在 `vup.lps` 里自带一套配色（烧烤灰棕、学画画橄榄绿……），移植时 `Work` 类漏了这组字段。
`LPSConvert` 只映射带 `[Line]` 特性的属性，所以进度条一直是同一套天蓝。已补齐。

### 修掉的两处

- **完成提示数字错**：`info.count` 是整段工作的累计产出，原代码按「最后一分钟收入」写，数字对不上。已改为「本次收入 $X」。
- **进行中列表行不刷新**：开始工作后列表行还停在"锁定/开始"的样子，「停止」按钮出不来。改为签名比对，变了才重建。

## 已实现的功能（首版概览）

**桌宠本体**：透明全屏 + 桌面站立 · 呼吸/待机/移动动画（621 组，含 APNG 动图）· 拖拽跟手 1:1 · 摸头/摸身体/长按捏脸 · 随机说话 · X11 鼠标穿透 · 置顶/回底

**数值玩法**：体力/心情/饱腹/口渴/金钱/经验/等级 + 生病状态机 · 商店（分类/搜索/排序/批量买/分页）· 物品栏（搜索/排序/收藏/连用/丢弃）· 投喂 122 种食物 · 工作学习玩耍 · 睡觉 · 12 条成就 · 角色面板（含陪伴年报）· 设置面板 · 自动保存

**没做的**：音效（无音频子系统）· 主题配色 · 多存档/图库/教程/托盘/多语言/联机 · 工作日程轮换/代理套餐/工作倍率

## 已知问题

- **鼠标穿透只在 X11（含 XWayland）下可用**。纯 Wayland 会话下自动降级为宠物大小的小窗，拖拽可用但无穿透 —— 这是协议限制，不是 bug。
- 依赖 .NET 8 运行时，未做自包含发布。
- 面板里的开关是点击式色块、数值用 `[−] 值 [+]` 步进器：没有引入 Avalonia 主题包，`CheckBox`/`MenuItem` 这类需要模板的控件不渲染，这是设计取舍。
- 部分合成器下托盘/任务栏图标不显示（无边框置顶窗口），属预期行为。
- 内存吃紧的机器上打开大列表可能 OOM，商店已分页规避。
