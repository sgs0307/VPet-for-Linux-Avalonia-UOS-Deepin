# VPet for Linux (Avalonia) v1.4.0 — 角色面板界面重做

这次只改界面，不动玩法数值。

## 界面

原来的角色面板（旧截图里叫"数据面板"）是一列到底的文本清单：七条属性共用同一个蓝色系统进度条，
能力、陪伴记录、陪伴年报全堆在同一列里，得一直往下滚才能看完。

现在：

| 区域 | 现在的样子 |
|---|---|
| 头部 | 名字 + `Lv` 徽章 + 状态徽章（发呆 / 干活 / 睡觉 / 生病各一色）+ 右上角 `×` |
| 导航 | **概览 / 记录 / 年报** 三个页签，头部固定不动 |
| 概览 | 4 张数值卡（金钱 / 背包 / 相伴天数 / 成就）+ 7 条属性条 + 4 张能力卡 |
| 记录 | 摸头 · 摸身体 / 捏脸 / 投喂 / 完成工作 / 已经陪你 / 一起干活 六张卡 + 时间线 |
| 年报 | 互动总数、最常吃两张主卡 + 睡得最久 / 最高等级 / 最有钱时 / 完成工作 / 成就 |

## 交互

- **属性条按语义上色**：体力橙红、饱腹橙、口渴浅蓝、心情粉、健康绿、好感紫、经验金 ——
  七条一样的蓝条变成一眼能分清的颜色。
- **低于 25% 转红**，只对生存类属性生效（经验和好感从 0 起步是正常的，不误报）。
- **悬停属性行**：整行高亮，底部提示条说明这个数值怎么涨、怎么掉、掉光会怎样。
- **每秒刷新不再重建控件**：以前滚到一半会被打回顶部、鼠标高亮每秒被抹掉；现在只改文本和条宽，
  滚动位置和悬停状态都保留。

## 安装

沿用 v1.3.1 的自包含包，**不需要安装 .NET**：

```bash
tar xzf VPet-UOS-v1.4.0-linux-x64-full.tar.gz
cd VPet-UOS-v1.4.0
./scripts/install.sh          # sh install.sh 也行
```

升级安装会先结束正在运行的桌宠（正常退出会保存存档），再用 `rsync` 覆盖，不会触发 SIGBUS。

- 会话内自检 `VPET_SELFTEST_ONLY=panels`（P8~P12）全过

## 已知限制（未变）

- 鼠标穿透只在 X11（含 XWayland）下可用，纯 Wayland 会话降级为小窗
- 无音频子系统，音量/音效设置不生效
- 面板控件是自绘的（没引入 Avalonia 主题包），所以开关是点击式色块、数值是 `[−] 值 [+]` 步进器
