# VPet 原版功能 vs Avalonia 移植版 — 差距清单

> 基线：`VPet-Simulator.Windows`（原版 WPF 宿主层）+ `VPet-Simulator.Core`（原版核心库）
> 对比对象：`src/` 下四个 Avalonia 工程
> 生成日期：2026-11-03 ｜ 最近更新：2026-11-18（v1.3.1）

## 一、已实现（与原版对齐）

| 功能 | 说明 |
|---|---|
| 桌宠渲染/动画 | PNG 序列 / 静态图 / **APNG 动图**均可播放（APNG 于 v1.2.5 补齐：完整 fcTL/fdAT 解析 + dispose/blend 合成），621 组动画加载 |
| 数值系统 | 体力/心情/饱腹/口渴/金钱/经验/等级 + Mode 状态机（含生病判定） |
| 摸头 / 摸身体 | 触摸区命中 + 数值反馈 + 动画 |
| 移动动画 | 16 个 move（爬行等），EventTimer 随机触发 |
| 拖动 / 置顶 / 鼠标穿透 / 回底 | X11 全屏透明窗 + XShape |
| 消息气泡 | MessageBar：Show / ShowMessage / AppendMessage / 自动隐藏 |
| 工作/学习/睡觉状态机 | MainLogic 数值变化逻辑完整（WorkingState、StartWork、效率计算） |
| WorkTimer UI | 骨架可用（进度条/停止按钮），样式未接线 |
| 存档 | 启动读取 + 退出保存（GameSave.Save/Load），全字段读写已实机校验 |
| **投喂系统**（v1.1.0） | 右键菜单「投喂」→ 食物列表（按类型/价格分组），播放 eat/drink/gift 夹心动画的**后层**（完整宠物本体，v1.1.7 起；夹心动画的三层容器尚未实现，看不到飞进嘴里的食物图标），扣背包、加数值、气泡播报 |
| **食物数据库**（v1.1.0） | 从 `mod/*/food/*.lps` 加载 122 种食物（Meal/Snack/Drink/Drug/Gift），含 `zh-Hans` 中文名映射 |
| **背包**（v1.1.0） | `inventory.txt` 独立持久化，不污染原存档格式；新手首次启动发放补给。v1.3.0 起支持搜索/排序/收藏（`favorites.txt`） |
| **商店**（v1.1.0 / v1.3.0 补全） | 分类筛选（带数量角标）＋ 名称/价格搜索 ＋ 四种排序（含性价比）＋ 批量购买 ×1/×5/×10 ＋ 只看买得起；钱只够一部分时按最大可买件数成交并说明；每页 12 条分页（控件量降到 1/10） |
| **工作/学习面板**（v1.1.0 / v1.3.1 补全） | 三分类（工作/学习/玩耍）＋ 每项显示时长/收益速度/总收益/消耗/等级要求 ＋ 等级不足压暗并显示 `Lv.N` ＋ ★收藏置顶（`workfavorites.txt`，MOD 自带配色应用于进度条）＋ 进行中高亮与实时进度；数值结算与 WorkTimer 自 v1.1.0 起即完整 |
| **睡觉 / 唤醒**（v1.1.0） | 菜单一键切换 `WorkingState.Sleep`，气泡提示，状态复位 |
| **自动保存**（v1.1.0） | 5 分钟 DispatcherTimer 定时保存（存档 + 背包），退出时再存一次 |
| **设置面板**（v1.2.0 / v1.3.0 补全） | 数据计算开关 / 计算间隔 / 互动周期 / 自动保存间隔 / 随机说话 / 说话频率 / 气泡停留 / 自己走动 / 开机自启 ＋ 数据管理（备份存档、打开数据目录、清除陪伴统计、关于），改动即时生效并存 `settings.txt` |
| **随机说话**（v1.2.0） | 15 个场景 60+ 句内置台词，按处境（生病/饿/渴/累）与时段选词，支持 `speech.txt` 自定义 |
| **角色面板**（v1.2.0 / v1.3.0 补全, v1.4.0 重做界面） | 概览（4 张数值卡 + 七项彩色属性条 + 能力上限 + 悬停说明）/ 记录 / **陪伴年报**（互动总数、睡眠时长、完成工作、最常吃、最高等级、最有钱时、成就进度） |
| **统计与成就**（v1.2.2） | 12 条本地成就（摸头/捏脸/投喂/购买/陪伴/干活/等级/金钱/睡觉），解锁落 `achievements.txt`（删档不清），气泡播报；峰值类（等级/金钱）持续观察。右键「成就」面板可看进度条与解锁时间 |
| **捏脸**（v1.2.2） | 长按机制补齐（600ms DispatcherTimer + 位移阈值取消）；pinch 触摸区从 GraphConfig 解析，动画 A_Start→B_Loop（按住循环）→C_End；数值等同摸头 |
| **物品栏**（v1.2.2 / v1.3.0 补全） | 分类过滤（带件数）、搜索（名字/类型/效果/价格上限）、四种排序、收藏置顶、使用 1 份或一次连用多份（吃不掉自动退回）、丢弃、总价值 |
| **拖动跟手**（v1.2.4） | 全屏窗口路径 + `BeginDragShape`（拖动期间输入区域临时放大到整窗，不逐帧下发 XShape），实测指针位移与宠物位移 1:1；缩窗拖动降级为 `VPET_SMALLWIN=1` 可选 |
| **位图缓存 LRU**（v1.2.3） | 96 张上限，淘汰即释放；并发重复解码不再漏原生内存 |
| MOD 加载 | 单 mod 目录（0000_core 萝莉斯） |
| 窗口图标 + 桌面快捷方式 | 原版 vpeticon |

## 二、未实现清单

> **进度（v1.3.0，2026-11-18）**：A 区 #1–#6 全部完成且已补成完整版（商店/设置不再是简版）；
> B 区 #7 角色面板、#8 统计成就、#10 捏脸、#12 物品栏完成（后三项均补齐简版缺的能力）；
> C 区 #17 自动保存、#21 开机自启完成。剩余 9 项，主要是
> B 区窗口类功能（存档管理/图库/日程/对话/教程）与 C 区系统级增强（多 MOD/托盘/找宠/DIY/多语言/联机）。

## 四、备注

- 移植进度文档（`VPet-Avalonia-移植进度.md`）为早期版本，其中"动画系统 0% / UI 交互 0%"早已过时：动画、交互、拖动、穿透、面板均已完成并实机验证。
- 原版窗口大量依赖 Panuon.WPF（无 Avalonia 版），移植时 UI 需全部重写，逻辑层可参考原版直接迁移。
