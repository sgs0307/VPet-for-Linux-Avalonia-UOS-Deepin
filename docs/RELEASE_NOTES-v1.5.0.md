# VPet Linux (Avalonia) v1.5.0

**界面统一。** 五个面板（商店 / 物品栏 / 工作 / 成就 / 设置）全部改用 v1.4.0 角色面板那套设计语言，
另外补了多语言 README。

## 为什么要改

v1.4.0 只重做了角色面板，其余五个面板还是老观感：分类、排序、购买一律用系统 `Button`（直角灰块、
hover 是系统色），每个面板底部挂一个占满整行的大「关闭」，列表靠 1px 分隔线平铺、没有卡片层次。
两个面板并排打开像两个不同的软件。

「看着老」的根源在控件模版，调 Property 解决不了，所以这一版是**换实现**：

| 组件 | 替代了什么 |
|---|---|
| 胶囊页签 / 筛选（`Border` 手绘 + 指针事件） | 系统 `Button` |
| 胶囊动作按钮 | ×1/×5/×10、用、全、弃、开始、停止、翻页 |
| 徽章 | 进行中 / 需要 Lv.N / 生病中 / 已有 N / 件数 |
| 卡片行 | 1px 分隔线平铺 |
| 圆角搜索框外壳 / 分组卡 / 只读属性条 | 裸 TextBox、一列到底 |

全部抽到 `Views/MainWindow.UiKit.cs`，六个面板共用一份定义。

## 各面板

- **外壳**：标题下加一行灰色副标题，专门放会变的状态（余额、条数、页码、工作进度），不再随列表滚走；
  关闭统一挪到右上角圆形 `×`，删掉底部大按钮，省下的一行高度还给内容
- **商店**：行改卡片；分类用彩色文字（正餐橙 / 饮料蓝 / 零食粉 / 药品绿 / 礼品紫）；
  单价与批量按钮上下两行排版，把宽度让给效果描述
- **物品栏**：行改卡片，星标独立 24px 热区，`×N` 用徽章；汇总移到副标题
- **工作 / 学习**：行改卡片；等级不足直接显示「需要 Lv.N」徽章（不用点下去才知道）；
  正在进行的项多一条实时进度条
- **成就**：每条一张卡，已解锁金色底 + 金条 + 「已达成」徽章，未解锁灰色 + 天蓝条；总进度单独一张卡
- **设置**：每个分组一张卡（数据计算 / 说话 / 行为 / 数据 / 系统 / 关于），开关与步进器改胶囊

## 顺手修的真 bug

**「关于」里的版本号一直是 1.3.1。** `AppInfo.Version` 是硬编码常量，v1.4.0 / v1.4.1 两次发版都忘了改，
所以刚发出去的 v1.4.1 里写的还是 1.3.1。现在运行时优先读随包的 `VERSION` 文件，读不到才回退常量；
`install.sh` 也补了 `VERSION` 拷贝（否则装完仍是编译期兜底值）。

另外：设置里「数据计算」分组下有一行同名开关，改叫「启用计算」。

四个文件内容对齐（功能表、安装步骤、目录结构、已知限制、开发踩坑），顶部有语言切换行。
`release.sh` 改为遍历 `README*.md` 批量改版本号与包文件名，以后发版不会再出现「徽章是新版、
下载表格是旧版」这种错位。

## 升级

存档、设置、统计、收藏、成就全部沿用，不需要迁移。安装方式不变：

```bash
tar xzf VPet-UOS-v1.5.0-linux-arm64-full.tar.gz
cd VPet-UOS-v1.5.0
./scripts/install.sh
```

包仍然是**自包含**的，不需要装 .NET 运行时。x86_64 机器把文件名换成 `x64`。
